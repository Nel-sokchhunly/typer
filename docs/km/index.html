ទាញយកសម្រាប់ macOS ទាញយកសម្រាប់ Windows ទាញយកសម្រាប់ Linux

macOS 13 Ventura ឬថ្មីជាងនេះ (Apple Silicon និង Intel) · Windows 10 ឬ 11 ប្រភេទ 64-bit · Ubuntu 22.04+ / Debian 12+ · ជំនាន់សាកល្បង៖ ពេលខ្លះវាអាចទាយខុស ហើយវារៀនពីអ្វីដែលអ្នកជ្រើសរើស។

ទៅកាន់ ដំឡើងលើ macOS ដំឡើងលើ Windows ដំឡើងលើ Linux របៀបប្រើ ឯកជនភាព ធ្វើបច្ចុប្បន្នភាព លុបចេញ មានបញ្ហា?

ដំឡើងលើ macOS

ចំណាយពេលប្រហែលពីរនាទី។

1 បើកកម្មវិធីដំឡើង

ចុច ទាញយកសម្រាប់ macOS ខាងលើ បន្ទាប់មកចុចពីរដងលើ Typer.pkg ក្នុងថត Downloads ហើយចុចបន្តតាមកម្មវិធីដំឡើងរហូតដល់ចប់។

macOS ថាមិនអាចផ្ទៀងផ្ទាត់ Typer បាន? Typer មិនទាន់មានវិញ្ញាបនបត្រ Apple Developer (បង់ប្រាក់) នៅឡើយទេ។ បើក System Settings → Privacy & Security រំកិលចុះក្រោម ចុច Open Anyway នៅជាប់ Typer.pkg រួចបញ្ជាក់។ លើ macOS 13 ឬ 14 អ្នកក៏អាចចុច Control លើ Typer.pkg ហើយជ្រើស Open បានដែរ។ ធ្វើបែបនេះតែពេលអ្នកទាញយកឯកសារពីទំព័រនេះប៉ុណ្ណោះ។

ចូលចិត្តប្រើ Terminal ជាង?

បើក Terminal (ចុច ⌘ Space វាយ Terminal ហើយចុច Return)។ បិទភ្ជាប់ពាក្យបញ្ជានេះ ហើយចុច Return៖

curl -fsSL -o /tmp/Typer-macos.zip https://github.com/Nel-sokchhunly/typer/releases/latest/download/Typer-macos.zip
mkdir -p ~/Library/Input\ Methods
rm -rf ~/Library/Input\ Methods/Typer.app
ditto -x -k /tmp/Typer-macos.zip ~/Library/Input\ Methods/
xattr -dr com.apple.quarantine ~/Library/Input\ Methods/Typer.app
echo "Typer installed"

វាទាញយក Typer ហើយដាក់វាក្នុងថត Input Methods របស់អ្នក។ បន្ទាត់ xattr ដកការរារាំងឯកសារទាញយករបស់ macOS ចេញ សម្រាប់តែ Typer ប៉ុណ្ណោះ។

មិនថាវិធីណាក៏ដោយ Typer ត្រូវបានដាក់តែក្នុងថត Input Methods របស់អ្នកប៉ុណ្ណោះ។

2 បើកការកំណត់ Keyboard

បើក System Settings → Keyboard។ នៅក្រោម Text Input ចុច Edit… នៅជាប់ Input Sources។

3 បន្ថែម Typer

ចុច + នៅជ្រុងខាងក្រោមខាងឆ្វេង។ ជ្រើស Khmer នៅខាងឆ្វេង ជ្រើស Typer / សរសេរ នៅខាងស្តាំ ហើយចុច Add។

រកមិនឃើញ Typer ក្នុងបញ្ជី? សូម Log Out ហើយចូលវិញ (ម៉ឺនុយ Apple → Log Out) រួចសាកម្តងទៀត។

4 ពិនិត្យថាវាបើកហើយ

ឥឡូវ Typer បង្ហាញក្នុង Input Sources របស់អ្នកហើយ។ បើក Show Input menu in menu bar ដើម្បីងាយមើលថាមួយណាកំពុងប្រើ រួចចុច Done។

ដំឡើងលើ Windows

ចំណាយពេលប្រហែលមួយនាទី។ Windows ទើបតែគាំទ្រថ្មីៗ សូមរាយការណ៍ប្រសិនបើមានអ្វីមិនដំណើរការ។

1 បើកកម្មវិធីដំឡើង

ចុច ទាញយកសម្រាប់ Windows ខាងលើ បន្ទាប់មកបើក Typer-windows-setup.exe ពីថត Downloads។ ចុច Install រួច Finish។

Windows បង្ហាញ "Windows protected your PC"? Typer មិនទាន់មានវិញ្ញាបនបត្រ (បង់ប្រាក់) នៅឡើយទេ។ ចុច More info រួច Run anyway។ ធ្វើបែបនេះតែពេលអ្នកទាញយកឯកសារពីទំព័រនេះប៉ុណ្ណោះ។

2 ប្តូរទៅ Typer

ចុច Windows Space ហើយជ្រើស Typer / សរសេរ (នៅក្រោម Khmer)។ កម្មវិធីដំឡើងបានបន្ថែមវារួចហើយ ដូច្នេះមិនចាំបាច់កំណត់អ្វីក្នុង Settings ទេ។

អ្វីៗខាងក្រោមដំណើរការដូចគ្នាលើ Windows លើកលែងតែការជ្រើសដោយកណ្តុរ៖ សូមប្រើ Enter ឬលេខជំនួសវិញ។

ដំឡើងលើ Linux

សម្រាប់ Ubuntu 22.04 ឬថ្មីជាងនេះ និង Debian 12 ឬថ្មីជាងនេះ (64-bit Intel/AMD) ដែលប្រើប្រព័ន្ធវាយអក្សរ IBus ធម្មតា។ Linux ទើបតែគាំទ្រថ្មីៗ សូមរាយការណ៍ប្រសិនបើមានអ្វីមិនដំណើរការ។

1 ដំឡើងកញ្ចប់

ចុច ទាញយកសម្រាប់ Linux ខាងលើ បន្ទាប់មកបើក Typer-linux-amd64.deb ពីថត Downloads ហើយចុច Install។ ឬក្នុង terminal៖

sudo apt install ./Downloads/Typer-linux-amd64.deb

2 Log Out ហើយចូលវិញ

3 បន្ថែម Typer

បើក Settings → Keyboard។ នៅក្រោម Input Sources ចុច + Add Input Source ជ្រើស Khmer បន្ទាប់មក Typer / សរសេរ ហើយចុច Add។ ប្តូរទៅវាដោយចុច Super Space។

អ្វីៗខាងក្រោមដំណើរការដូចគ្នាលើ Linux រួមទាំងការជ្រើសដោយកណ្តុរ។ អ្នកប្រើ KDE ដែលប្រើ Fcitx5 មិនទាន់គាំទ្រនៅឡើយទេ។

ឯកជនភាព

អ្វីៗទាំងអស់នៅលើកុំព្យូទ័ររបស់អ្នក។ Typer មិនប្រើអ៊ីនធឺណិត ហើយមិនផ្ញើអ្វីទៅកន្លែងណាទេ។ ពាក្យដែលអ្នកជ្រើស ត្រូវបានរក្សាទុកក្នុងម៉ាស៊ីន ដើម្បីឱ្យ Typer អាចរៀន៖ ក្នុង ~/Library/Application Support/Typer/ លើ Mac និង %APPDATA%\Typer លើ Windows និង ~/.local/share/typer/ លើ Linux។ លុបថតនោះពេលណាក៏បាន ដើម្បីចាប់ផ្តើមឡើងវិញ។

ធ្វើបច្ចុប្បន្នភាព

ទាញយក ហើយបើកកម្មវិធីដំឡើងម្តងទៀត (លើ Mac អ្នកក៏អាចប្រើពាក្យបញ្ជា Terminal បានដែរ)។ អ្វីដែល Typer បានរៀនរួច នៅតែរក្សាទុក។ លើ Windows កម្មវិធីដែលកំពុងបើកពេលធ្វើបច្ចុប្បន្នភាព នឹងប្តូរទៅជំនាន់ថ្មីបន្ទាប់ពីបើកម៉ាស៊ីនឡើងវិញ។ បើវានៅតែដំណើរការដូចជំនាន់ចាស់ សូមប្តូរទៅ input source ផ្សេង រួចប្តូរមកវិញ ឬ Log Out ហើយចូលវិញ។

ដក Typer ចេញក្នុង System Settings → Keyboard → Input Sources → Edit… (ជ្រើសវា ហើយចុច −) រួចដំណើរការ៖

លើ Windows៖ Settings → Apps → Installed apps → Typer → Uninstall។

លើ Linux៖ sudo apt remove typer ហើយដក Typer ចេញពី Input Sources។

មានបញ្ហា?

  • គ្មានពាក្យណែនាំបង្ហាញ៖ ពិនិត្យថា Typer ត្រូវបានជ្រើសនៅលើរបារម៉ឺនុយ។ អ្នកប្រហែលជានៅក្នុងរបៀបអង់គ្លេស សូមចុច Ctrl ម្តង។
  • រកមិនឃើញ Typer ក្នុងបញ្ជី Add៖ Log Out ហើយចូលវិញ រួចសាកជំហានទី 3 ម្តងទៀត។
  • រូបតំណាង ឬដំណើរការនៅតែចាស់ក្រោយធ្វើបច្ចុប្បន្នភាព៖ ដំណើរការ killall -9 TextInputSwitcher TextInputMenuAgent ក្នុង Terminal (macOS នឹងបើកវាឡើងវិញ) ឬដក Typer ចេញពី Input Sources ហើយបន្ថែមវិញ ឬ Log Out ហើយចូលវិញ។
  • ពាក្យណែនាំខុស៖ សូមរាយការណ៍ ដោយប្រាប់ពីអ្វីដែលអ្នកបានវាយ និងអ្វីដែលអ្នករំពឹងចង់បាន។ របាយការណ៍ទាំងនេះជួយឱ្យ Typer កាន់តែល្អ។
