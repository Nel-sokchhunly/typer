Typer សរសេរ

Changes apply on your next keystroke.

Switch to Typer ប្តូរទៅ Typer

macOS: Ctrl Space or the 🌐 Globe key, or pick it from the input menu in the menu bar.
ចុច Ctrl Space ឬគ្រាប់ចុច 🌐 Globe ឬជ្រើសវាពីម៉ឺនុយ Input នៅលើរបារម៉ឺនុយ។

Windows: Windows Space, then choose Typer / សរសេរ.
ចុច Windows Space ហើយជ្រើស Typer / សរសេរ (នៅក្រោម Khmer)។

Linux: Super Space.
ចុច Super Space។

Try it សាកល្បង

Switch to Typer, then type knhom tov sala rean and press Enter.
ប្តូរទៅ Typer រួចវាយ knhom tov sala rean ហើយចុច Enter។

✓ ខ្ញុំទៅសាលារៀន

Type Khmer in Latin letters, with spaces between words. Type the whole phrase: the first suggestion is usually the whole phrase in Khmer.
វាយខ្មែរជាអក្សរឡាតាំង ដោយដកឃ្លារវាងពាក្យនីមួយៗ។ វាយឃ្លាទាំងមូលសិន ទើបជ្រើស៖ ពាក្យណែនាំទីមួយ ជាធម្មតាគឺឃ្លាទាំងមូលជាខ្មែរ។

Keys គ្រាប់ចុច

SpaceSeparate words. It never inserts anything, so keep typing
ដកឃ្លារវាងពាក្យ។ វាមិនបញ្ចូលអ្វីទេ ដូច្នេះវាយបន្តបាន
↓ ↑ or Tab / Shift TabMove through the suggestions
រំកិលក្នុងបញ្ជីពាក្យណែនាំ
EnterInsert the highlighted suggestion (the first one unless you moved)
បញ្ចូលពាក្យណែនាំដែលកំពុងរំលេច (ពាក្យទីមួយ បើអ្នកមិនបានរំកិល)
1 to 9, or clickInsert that suggestion
បញ្ចូលពាក្យណែនាំនោះ
EscInsert exactly what you typed, in Latin letters
បញ្ចូលតាមអ្វីដែលអ្នកវាយ ជាអក្សរឡាតាំង
BackspaceEdit what you're typing
កែអ្វីដែលអ្នកកំពុងវាយ

ប្តូររវាងខ្មែរ និងអង់គ្លេស

ស្លាកពណ៌លឿងតូច ខ ឬ EN នៅក្រោមទស្សន៍ទ្រនិច បង្ហាញរបៀបដែលកំពុងប្រើ។
